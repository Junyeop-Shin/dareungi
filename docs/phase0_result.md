## 계획 변경

- 고장신고 API 수집: 날짜마다 호출하지 않고 **한 번 호출 후 등록일시로 거른다**(07 문서)
- 전체 고장 건수의 기준을 **신고 건수(고유 자전거+일시)**로 정함. 공표치와 비교할 때만 행 수(02 문서)
- 중복 병합 규칙을 파일 단위가 아니라 **행 단위**로 고름(02 문서)
- 대여이력 적재: 연도 ZIP을 통째로 풀지 않고 **한 달치씩** 꺼내 처리. 상세 기간 용량 17GB → 23GB로 수정(05 문서)
- 2026년 대여이력의 자전거구분은 과거 기록·API로 채움(05 문서)
- `dist_bad` 표시와 거리 보정 규칙 추가(05 문서)
