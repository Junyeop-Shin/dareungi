| 항목 | 정의 |
|---|---|
| 예측 대상 | 부품별(타이어·체인·안장·페달) + 전체의 **향후 7일 합계** `y(t) = y[t] + … + y[t+6]` |

| 원점 분할 | Train 2020-01-01 ~ 2023-12-25 / Valid 2024-01-01 ~ 2024-12-25 / Test 2025-01-01 ~ 2026-06-24 (타깃 7일이 구간 안에 들어가게) |
| 주 지표 | MAE, MAE%, **skill = 1 − MAE/MAE(나이브 B1)**, 편향(예측 − 실제 평균) |
| 구간 지표 | 80% 예측구간 커버리지, pinball 손실(10%·90%) |
| 유의성 | Diebold-Mariano 검정(모형 vs 나이브, h = 7) |

### 예측 모형에 쓸 수 있는 날씨 변수

예보되지 않는 변수는 예측 모형에서 뺀다. 설명 모형(03)과 다른 점이다.

| 변수 | 예보 여부 | 예측 모형 사용 |
|---|---|---|
| 평균·최고·최저기온, 일교차, 동결융해 | 단기(D+0~2)·중기(D+3~) 예보 있음 | 사용 |
| 강수 유무·강수량 | 단기는 양, 중기는 확률·유무 | 강수 유무 중심, 강수량은 log1p |
| 적설 | 단기 예보 있음 | 사용 |
| 습도 | 단기만 | 선택(쓰면 D+3 이후는 기후값) |
| 일사량·일조시간·지면온도 | **예보 없음** | 사용하지 않음 |

## 1C-1. 평가 하네스와 나이브 (1일) — `py/fc.py`

```python
import numpy as np, pandas as pd
from pathlib import Path
ROOT = Path(__file__).resolve().parents[1]          # py/의 상위 = 프로젝트 폴더

m = pd.read_parquet(ROOT / "data/processed/daily_master_v2.parquet").sort_values("date").reset_index(drop=True)
bool_cols = m.select_dtypes(bool).columns
m[bool_cols] = m[bool_cols].astype(int)             # 참/거짓 → 0/1 (아래 '왜' 참고)
m["snow_any"] = (m.snow_cm > 0).astype(int)
PARTS = ["fail_tire", "fail_chain", "fail_saddle", "fail_pedal", "total_faults"]

def split_of(o):
    o = pd.Series(o)
    return np.select([o.between("2020-01-01", "2023-12-25"),
                      o.between("2024-01-01", "2024-12-25"),
                      o.between("2025-01-01", "2026-06-24")], ["train", "valid", "test"], default=None)

def sum7_fwd(s):   return s[::-1].rolling(7).sum()[::-1]      # t..t+6
def sum7_back(s):  return s.rolling(7).sum().shift(1)          # t-7..t-1
def sum28_back(s): return s.rolling(28).sum().shift(1)         # t-28..t-1

def make_base():
    rows = []
    for p in PARTS:
        x = m[p]
        rows.append(pd.DataFrame({
            "origin": m.date, "part": p, "y": sum7_fwd(x),
            "B1": sum7_back(x),                                           # 지난주 합계
            "B2": sum28_back(x) / 4,                                      # 최근 4주 평균 × 7
            "B3": sum7_fwd(x).shift(364),                                 # 작년 같은 주(요일 맞춤)
            "B4": sum7_fwd(x).shift(364) * sum28_back(x) / sum28_back(x).shift(364)}))  # × 최근 증감률
    base = pd.concat(rows, ignore_index=True)
    base["split"] = split_of(base.origin)
    return base.dropna(subset=["split", "y"]).reset_index(drop=True)

def score(preds, base):
    """preds: origin, part, model, pred. 부품마다 '모든 모형이 예측한 원점'만 채점한다."""
    df = preds.merge(base[["origin", "part", "split", "y", "B1"]], on=["origin", "part"])
    n_all = df.groupby("part").model.transform("nunique")
    n_here = df.groupby(["origin", "part"]).model.transform("nunique")
    df = df[n_here == n_all].assign(ae=lambda x: (x.pred - x.y).abs(),
                                    ae_b1=lambda x: (x.B1 - x.y).abs(),
                                    err=lambda x: x.pred - x.y)
    out = df.groupby(["split", "part", "model"]).agg(
        n=("y", "size"), MAE=("ae", "mean"), y_mean=("y", "mean"),
        MAE_B1=("ae_b1", "mean"), bias=("err", "mean")).reset_index()
    out["MAEpct"] = 100 * out.MAE / out.y_mean
    out["skill"] = 1 - out.MAE / out.MAE_B1
    return out.drop(columns=["y_mean", "MAE_B1"])
```

**왜 참/거짓을 0/1로 바꾸나:** 7일짜리 예측용 데이터에 공휴일이 하루도 없으면 범주가 하나뿐이라 설계행렬이 학습 때와 달라질 수 있다. 또 시나리오 D에서 강수 유무에 확률값(예: 0.3)을 넣어야 한다.

노트북에서:


## 1C-2. 날씨 시나리오 만들기 (반나절)

| 시나리오 | 미래 7일 날씨 | 의미 |
|---|---|---|
| A 실측 | 실제 관측값 | 상한선(완벽한 예보). 1차가 쓴 방식 |
| B 실제 예보 | 기상청 과거 예보 | 가장 현실적. 과거 단기예보 자료를 구할 수 있으면 사용(기상자료개방포털 확인). 단계 3부터는 직접 저장한다 |
| C 오차 주입 | 실측 + 예보 오차 흉내 | B를 못 구할 때의 대안 |
| D 날씨 없음 | 월별 기후값 | 날씨 정보가 전혀 없을 때 |

```python
WX = ["tavg", "tmax", "tmin", "rain_mm", "rain_any", "snow_any", "freeze_thaw", "temp_range"]

def perturb(wx7, seed):
    """wx7: 원점부터 7일. 같은 원점(seed)은 모든 모형·부품에서 같은 오차를 받는다."""
    rng  = np.random.default_rng(seed)
    lead = np.arange(7)
    e    = rng.normal(0, 1.0 + 0.25 * lead)           # 기온 오차: D+0 1.0℃ → D+6 2.5℃ (가정)
    flip = rng.random(7) < (0.10 + 0.03 * lead)       # 강수 유무 오판: 10% → 28% (가정)
    noise = np.exp(rng.normal(0, 0.5, 7))
    w = wx7.copy()
    for c in ("tavg", "tmax", "tmin"):
        w[c] = w[c].to_numpy() + e
    ra = np.where(flip, 1 - w.rain_any.to_numpy(), w.rain_any.to_numpy())
    w["rain_mm"] = np.where(flip & (ra == 1), 5.0,                 # 맑음 → 비로 오판: 5mm로 가정
                            np.where(ra == 0, 0.0, w.rain_mm.to_numpy() * noise))
    w["rain_any"] = ra
    w["temp_range"] = w.tmax - w.tmin
    w["freeze_thaw"] = ((w.tmin < 0) & (w.tmax > 0)).astype(int)
    return w

CLIM = m[m.date.between("2020-01-01", "2023-12-31")].groupby("month")[WX].mean()   # 학습 구간 월별 기후값

def scenario_wx(nd, scn, seed):
    """nd: 원점부터 7일 행. 반환: 같은 인덱스의 날씨 열"""
    if scn == "A":
        return nd[WX].copy()
    if scn == "C":
        return perturb(nd[WX], seed)
    if scn == "D":
        return CLIM.loc[nd.month.to_numpy()].set_axis(nd.index)
    raise ValueError("시나리오 B는 과거 예보 자료를 붙여 구현")
```

오차 크기(1.0~2.5℃, 10~28%)는 **가정**이다. 보고서에 그대로 적고, 가능하면 단계 3에서 모은 실제 예보로 다시 잰다.

## 1C-3. 노출(대여량) 예측 모형 (1일)

'고장률 × 노출' 구조(M2)와 LightGBM 입력에 필요하다. 03에서 고른 노출 변수를 `expo`로 둔다.

```python
import statsmodels.api as sm, statsmodels.formula.api as smf

m["expo"] = m.dist_km                                               # 03 체크포인트 C 결과로
m["expo_lvl"] = m.expo.rolling(28).mean().shift(7)                  # d-34..d-7일 평균

def fit_nb_glm(formula, data, offset=None):
    """음이항: 이산 모형으로 alpha 추정 → alpha 고정 GLM. 반환: (GLM 결과, alpha)"""
    alpha = smf.negativebinomial(formula, data=data, offset=offset).fit(disp=0, maxiter=500).params["alpha"]
    res = smf.glm(formula, data=data, family=sm.families.NegativeBinomial(alpha=alpha), offset=offset).fit()
    return res, alpha

TR = m[m.date.between("2020-01-01", "2023-12-31")].copy()
TR["expo_int"] = TR.expo.round()
f_expo = ("expo_int ~ np.log(expo_lvl) + C(dow) + is_holiday + after_off + bridge + fs1 + fc1 + fs2 + fc2"
          " + bs(tavg, df=4) + rain_any + np.log1p(rain_mm) + snow_any + covid")
expo_model, _ = fit_nb_glm(f_expo, TR)

def predict_expo(i, scn):
    nd = m.iloc[i:i + 7].copy()
    nd[WX] = scenario_wx(nd, scn, seed=i).to_numpy()
    return np.asarray(expo_model.predict(nd))
```

`expo_lvl`은 d−34 ~ d−7일 평균이라, 원점 t에서 t+6까지 예측할 때도 t−1일까지의 정보만 쓴다(누수 없음).

- [ ] Valid에서 주간 노출 예측의 MAE%를 기록한다(참고: 1차 노트북에서 대여량 XGBoost MAPE 18.5%). 노출 예측이 나쁘면 M2도 나빠진다
- [ ] LightGBM으로 바꿔 보고 더 나으면 교체한다(선택)

## 1C-4. M1 — ARIMAX (1일)

통계 시계열 기준 모형이다. 계절성은 Fourier 항과 요일 더미가 맡는다. 1차의 SARIMA(…)[365]는 쓰지 않는다.

```python
import itertools, warnings
from statsmodels.tsa.statespace.sarimax import SARIMAX

def build_X(df):
    dow = pd.get_dummies(pd.Categorical(df.dow, categories=range(1, 8)), prefix="dow", drop_first=True)
    X = pd.concat([dow.set_axis(df.index),
                   df[["is_holiday", "after_off", "fs1", "fc1", "fs2", "fc2", "tavg", "rain_any", "snow_any"]]], axis=1)
    return X.astype(float)

X_ALL = build_X(m)
TR_IDX = np.where(m.date.between("2020-01-01", "2023-12-31"))[0]

def fit_best_arima(p):
    """작은 격자에서 AIC가 가장 낮은 (p,d,q)"""
    y, X = m[p].to_numpy()[TR_IDX], X_ALL.iloc[TR_IDX]
    best = None
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")
        for order in itertools.product([0, 1, 2], [0, 1], [0, 1, 2]):
            try:
                r = SARIMAX(y, exog=X, order=order).fit(disp=False)
                if best is None or r.aic < best.aic:
                    best = r
            except Exception:
                pass
    return best

FIT_ARIMA = {p: fit_best_arima(p) for p in PARTS}          # 부품당 18개 적합. 몇 분 걸린다

def fc_arima(p, i, scn):
    hist = np.arange(TR_IDX[0], i)
    r = FIT_ARIMA[p].apply(m[p].to_numpy()[hist], exog=X_ALL.iloc[hist])   # 같은 계수로 다시 필터링만(재추정 없음)
    nd = m.iloc[i:i + 7].copy()
    nd[WX] = scenario_wx(nd, scn, seed=i).to_numpy()
    return float(np.clip(np.asarray(r.forecast(steps=7, exog=build_X(nd))), 0, None).sum())
```

- 원점 수백 개 × 부품 5개라 수 분~십여 분 걸린다. 오래 걸리면 `joblib.Parallel`로 부품별 병렬화한다
- `FIT_ARIMA[p].specification`으로 고른 차수를 기록한다

## 1C-5. M2 — 음이항 고장률 × 노출 예측 (1.5일)

03의 설명 모형을 **예측에 쓸 수 있는 변수만으로** 다시 적합한다. 연도 고정효과 대신 '최근 고장률 수준'을 넣어 레짐 변화에 적응하게 한다.

```python
def add_rate_lvl(df, p):     # d-34..d-7일의 고장률 (부품별)
    return df.assign(rate_lvl=df[p].rolling(28).sum().shift(7) / df.expo.rolling(28).sum().shift(7))

RHS_FC = ("np.log(rate_lvl) + C(dow) + is_holiday + after_off + bridge + fs1 + fc1 + fs2 + fc2"
          " + bs(tavg, df=4) + rain_any + np.log1p(rain_mm) + np.log1p(rain_lag1) + snow_any + freeze_thaw + covid")

LVL = {p: add_rate_lvl(m, p) for p in PARTS}
FIT_GLM = {}
for p in PARTS:
    dp = LVL[p][LVL[p].date.between("2020-01-01", "2023-12-31")]
    FIT_GLM[p] = fit_nb_glm(f"{p} ~ {RHS_FC}", dp, offset=np.log(dp.expo))      # (결과, alpha)
```

원점별 예측과 예측구간(음이항 시뮬레이션):

```python
RNG = np.random.default_rng(42)

def fc_glm(p, i, scn, nsim=2000):
    res, alpha = FIT_GLM[p]
    nd = LVL[p].iloc[i:i + 7].copy()
    wx = scenario_wx(nd, scn, seed=i)
    nd[WX] = wx.to_numpy()
    nd["rain_lag1"] = np.r_[LVL[p].rain_mm.iat[i - 1], wx.rain_mm.to_numpy()[:6]]   # 첫날의 '전날'은 실측
    mu = np.asarray(res.predict(nd, offset=np.log(predict_expo(i, scn))))           # 노출은 예측값
    size = 1 / alpha                                                                # NB2: 분산 = mu + alpha·mu²
    sims = RNG.negative_binomial(size, size / (size + mu), size=(nsim, 7)).sum(axis=1)
    return {"pred": mu.sum(), "q10": np.quantile(sims, 0.1), "q90": np.quantile(sims, 0.9)}
```

원점 전체를 돌려 하네스 형식(`origin, part, model, pred, q10, q90`)으로 모은다. ARIMA도 같은 방식이다.

```python
valid_idx = np.where(split_of(m.date) == "valid")[0]

glm_preds = pd.DataFrame([{"origin": m.date.iat[i], "part": p, "model": "M2_glm_C", **fc_glm(p, i, "C")}
                          for p in PARTS for i in valid_idx])
arima_preds = pd.DataFrame([{"origin": m.date.iat[i], "part": p, "model": "M1_arima_C", "pred": fc_arima(p, i, "C")}
                            for p in PARTS for i in valid_idx])
```

모형 이름에 시나리오를 붙여 둔다(`_A`, `_C`, `_D`). 1C-10에서 시나리오별 비교에 그대로 쓴다.

주의: 이 구간은 노출 예측 오차와 계수 불확실성을 빼고 계산해서 **실제보다 좁게** 나온다. 1C-8에서 검증 구간 오차로 보정한다.

- [ ] Valid에서 skill과 80% 커버리지를 기록한다
- [ ] '건수 직접' 버전(offset 없이 `np.log(최근 4주 평균 건수)`를 넣은 것)도 한 번 돌려 비교한다. 레짐 변화 구간에서 어느 쪽이 나은지가 보고서 소재다

## 1C-6. M3 — LightGBM 주간 직접 예측 (1.5일)

원점마다 한 행을 만들고 타깃을 7일 합계로 둔다. 반복 예측이 필요 없고 분위수 예측이 쉽다.

```python
def week_feats(p, scn="A"):
    x, e = m[p], m.expo
    f = pd.DataFrame({
        "origin": m.date, "part": p,
        "y": sum7_fwd(x), "lw": sum7_back(x), "l4w": sum28_back(x) / 4, "ly": sum7_fwd(x).shift(364),
        "lw_expo": sum7_back(e), "rate4w": sum28_back(x) / sum28_back(e),
        "rain_lw": sum7_back(m.rain_mm),
        "n_off": sum7_fwd(m.is_off),                                   # 목표 주의 쉬는 날 수(확정)
        "doy_s": np.sin(2 * np.pi * m.doy / 365.25), "doy_c": np.cos(2 * np.pi * m.doy / 365.25)})
    f["split"] = split_of(f.origin)
    idx = np.where(f.split.notna() & f.y.notna())[0]
    wk = []
    for i in idx:                                                      # 목표 주 날씨 요약 + 노출 예측(시나리오별)
        wx = scenario_wx(m.iloc[i:i + 7], scn, seed=i)
        wk.append({"origin": m.date.iat[i], "w_tavg": wx.tavg.mean(), "w_tmax": wx.tmax.max(),
                   "w_tmin": wx.tmin.min(), "w_rain_days": wx.rain_any.sum(), "w_rain_sum": wx.rain_mm.sum(),
                   "w_freeze": wx.freeze_thaw.sum(), "expo_hat": predict_expo(i, scn).sum()})
    return f.iloc[idx].merge(pd.DataFrame(wk), on="origin")

FEATS = ["lw", "l4w", "ly", "lw_expo", "rate4w", "rain_lw", "n_off", "doy_s", "doy_c",
         "w_tavg", "w_tmax", "w_tmin", "w_rain_days", "w_rain_sum", "w_freeze", "expo_hat"]
```

학습(검증 구간으로 조기 종료)과 분위수 모형:

```python
import lightgbm as lgb

fo = week_feats("fail_tire", "A")
tr, va = fo[fo.split == "train"], fo[fo.split == "valid"]
params = dict(objective="poisson", learning_rate=0.03, num_leaves=15, min_data_in_leaf=40,
              feature_fraction=0.8, bagging_fraction=0.8, bagging_freq=1, lambda_l2=1.0, seed=42, verbose=-1)
model = lgb.train(params, lgb.Dataset(tr[FEATS], tr.y), num_boost_round=3000,
                  valid_sets=[lgb.Dataset(va[FEATS], va.y)],
                  callbacks=[lgb.early_stopping(100, verbose=False)])
q_models = {a: lgb.train({**params, "objective": "quantile", "alpha": a},
                         lgb.Dataset(tr[FEATS], tr.y), num_boost_round=model.best_iteration)
            for a in (0.1, 0.9)}

va = va.assign(pred=model.predict(va[FEATS], num_iteration=model.best_iteration),
               q10=q_models[0.1].predict(va[FEATS]), q90=q_models[0.9].predict(va[FEATS]))
lgb_preds = va.assign(model="M3_lgb_A")[["origin", "part", "model", "pred", "q10", "q90"]]
```

- **학습은 시나리오 A(실측 날씨)로, 예측은 시나리오별 특성으로** 한다. 예: `va_C = week_feats("fail_tire", "C").query("split == 'valid'")`를 같은 모형에 넣으면 오차 주입 시나리오 예측이 된다
- 하이퍼파라미터는 `num_leaves` {7, 15, 31}, `min_data_in_leaf` {20, 40, 80} 정도만 Valid로 고른다. 원점이 겹치는 행이라 과적합이 쉽다
- 변수 중요도 `model.feature_importance("gain")`를 저장한다. `lw`·`rate4w` 같은 수준 변수만 중요하면 사실상 나이브와 비슷한 모형이다

## 1C-7. M4 — LSTM/GRU (선택, 2일)

Valid에서 M2·M3를 이기지 못하면 테스트에 올리지 않는다. 이제 같은 파이썬 환경이라 Colab으로 옮길 필요가 없다(데이터가 작아 맥북 CPU로 충분). 1차 노트북 검토에서 나온 규칙을 지킨다.

1. 부품별로 모델 하나(`Dense(4)` 동시 출력 금지).
   - 입력 A: 과거 28일의 [부품 건수, 노출, 날씨, 달력]
   - 입력 B: 목표 7일의 [달력, 시나리오 날씨]
   - 출력: 7일 합계 1개
2. 스케일러는 Train 원점 구간 데이터로만 적합한다. 윈도우는 원점 날짜로 나눈 뒤 만든다.
3. 조기 종료와 모든 선택은 Valid 원점으로. Test는 마지막 한 번.
4. 예측을 `origin, part, model, pred` 형식으로 만들어 `score()`에 넣는다.

```python
from scipy import stats

def dm_test(e1, e2, h=7, power=1):
    """e1: 모형 오차, e2: 기준 오차. 음수 통계량 = 모형이 더 정확. (Harvey 등 소표본 보정 포함)"""
    d = np.abs(np.asarray(e1)) ** power - np.abs(np.asarray(e2)) ** power
    n, dbar = len(d), d.mean()
    gam = [np.mean((d[k:] - dbar) * (d[:n - k] - dbar)) for k in range(h)]
    stat = dbar / np.sqrt((gam[0] + 2 * sum(gam[1:])) / n)
    stat *= np.sqrt((n + 1 - 2 * h + h * (h - 1) / n) / n)
    return stat, 2 * stats.t.sf(abs(stat), df=n - 1)

sel = "M3_lgb_A"                                         # selection.csv에서 이 부품에 고른 모형 이름
t = (test_preds.query("part == 'fail_tire' and model in [@sel, 'B1']")
       .merge(base[["origin", "part", "y"]], on=["origin", "part"])
       .assign(e=lambda x: x.pred - x.y)
       .pivot(index="origin", columns="model", values="e").dropna())
dm_test(t[sel], t["B1"])                                  # 7일 합계가 겹쳐서 h = 7
```

```python
def pinball(y, q, tau):
    diff = np.asarray(y) - np.asarray(q)
    return np.mean(np.maximum(tau * diff, (tau - 1) * diff))
```

## 1C-10. 날씨 정보의 가치 (반나절)

선택 모형을 시나리오 A·C·D(가능하면 B)로 각각 Test 채점한다.

| 시나리오 | 타이어 skill | 체인 | 안장 | 페달 | 해석 |
|---|---|---|---|---|---|
| A 실측(상한) | | | | | 완벽한 예보가 있을 때 |
| C 오차 주입 | | | | | 현실적 추정 |
| D 날씨 없음 | | | | | 달력·수준만으로 |

- A와 C의 차이가 작다 → 예보 오차에 강하다(실무 투입 가능)
- C와 D의 차이가 작다 → 날씨가 주 단위 예측에 별 도움이 안 된다. 타이어처럼 계절 진폭이 큰 부품만 도움이 될 수 있다

   | 도구 | R + Colab(Keras) | Python 하나로 통일(pandas·statsmodels·lightgbm) |

3. **데이터와 레짐**: 2025 신고 감소와 원인 점검 결과

## 흔한 함정

- **원점별로 비교 행 수가 다르다** → `score()`처럼 공통 원점만 채점한다
- **이동 합계를 1일만 밀어 7일 합계 예측에 쓴다** → 과거 값은 t−1까지만(`shift(1)` 이상)
- **노출 실측값을 예측에 쓴다** → 누수. 노출은 1C-3에서 예측한 값만
- **일사량을 예측 모형에 넣는다** → 예보되지 않는 변수다
- **Valid로 조기 종료하고 Valid 점수를 그대로 최종 성능이라 부른다** → 최종 성능은 Test뿐
- **테스트 결과를 보고 모형을 바꾼다** → 바꾸면 그 테스트는 더 이상 테스트가 아니다. 바꿨다면 보고서에 밝힌다
- **MAPE로 일별 평가를 한다** → 0에 가까운 날에 폭발한다. MAE%·wMAPE를 쓴다
