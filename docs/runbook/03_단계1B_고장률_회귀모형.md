## 목표

1. 고장 **건수**가 아니라 **고장률**을 설명하는 모형으로 바꾼다. 대여량(노출)은 설명변수가 아니라 offset으로 내린다.
2. 모형을 한 번에 최종형으로 가지 않고 사다리(M0 → M4)로 올라가며, 단계마다 무엇이 바뀌는지 보여준다. "왜 이 모형인가"가 결과로 나온다.
3. 04 문서(예측)의 설계를 결정한다: 노출 변수, 날씨 변수 목록, 예측 타깃을 건수로 둘지 '고장률 × 노출'로 둘지.

## 도구: statsmodels

| 하고 싶은 것 | statsmodels |
|---|---|
| 식(formula)으로 모형 쓰기 | `statsmodels.formula.api`의 `smf.ols`, `smf.glm`, `smf.negativebinomial` |
| 범주형 | `C(dow)` |
| 스플라인(곡선) | `bs(tavg, df=4)` |
| offset | `offset=np.log(d["expo"])` |
| 음이항 과산포 모수(alpha) 추정 | `smf.negativebinomial(...).fit()` → `params["alpha"]` |
| HAC 표준오차 | `.fit(cov_type="HAC", cov_kwds={"maxlags": 14})` |

음이항은 **두 단계**로 적합한다. ① 이산형 음이항 모형으로 alpha를 추정하고 ② 그 alpha를 고정한 GLM으로 다시 적합하면서 HAC 표준오차를 구한다. GLM 쪽이 예측·신뢰구간·HAC 기능을 모두 안정적으로 지원한다.

```python
import numpy as np, pandas as pd
import statsmodels.api as sm
import statsmodels.formula.api as smf
from pathlib import Path
ROOT = Path("..")

def fit_nb(formula, data, expo="expo", maxlags=14):
    """음이항 + offset(log 노출). 반환: HAC 표준오차를 쓴 GLM 결과, alpha, 이산 모형 AIC"""
    y = formula.split("~")[0].strip()
    d = data.dropna(subset=[y, expo]).copy()
    off = np.log(d[expo])
    nb = smf.negativebinomial(formula, data=d, offset=off).fit(disp=0, maxiter=500)
    alpha = nb.params["alpha"]
    res = smf.glm(formula, data=d, family=sm.families.NegativeBinomial(alpha=alpha), offset=off) \
             .fit(cov_type="HAC", cov_kwds={"maxlags": maxlags})
    return res, alpha, nb.aic

def irr_table(res):
    ci = np.exp(res.conf_int())
    return pd.DataFrame({"irr": np.exp(res.params), "lo": ci[0], "hi": ci[1], "p_hac": res.pvalues})
```

**결측 주의:** 식이 결측 행을 자동으로 빼면 offset 길이와 어긋나 오류가 난다. 식에 쓰는 열에 결측이 없도록 먼저 확인한다(`d[cols].isna().sum()`).

## 1B-2. M1 → M3 — 카운트 모형으로, offset으로, 음이항으로 (1일)

```python
f_wx = "tavg + np.log1p(rain_mm) + snow_any + humidity + solar"

m1 = smf.glm(f"total_faults ~ {f_wx}", data=d, family=sm.families.Poisson()).fit()          # 노출 없음
m2 = smf.glm(f"total_faults ~ {f_wx}", data=d, family=sm.families.Poisson(),
             offset=np.log(d.expo)).fit()                                                      # + offset
print("과산포 비율:", m2.pearson_chi2 / m2.df_resid)                                            # 1보다 훨씬 크면 음이항

m3, alpha3, aic3 = fit_nb(f"total_faults ~ {f_wx}", d)                                         # 음이항 + offset
alpha3
```

| 단계 | 모형 | 드러나는 것 |
|---|---|---|
| M0 | OLS(1차 식) | 비교 기준. R²가 높아도 사실상 '대여량 단위 환산' |
| M1 | 포아송, 노출 없음 | 카운트 모형 출발점 |
| M2 | 포아송 + offset | 노출을 통제하면 기상 계수가 어떻게 바뀌는지 |
| M3 | 음이항 + offset | 과산포 해결. 1차의 이분산은 데이터 성질이 아니라 **모형을 잘못 고른 증상**이었다는 근거 |
| M4 | M3 + 확정 변수 | 최종 설명 모형 |

확인
- [ ] 과산포 비율을 기록한다. 1보다 훨씬 크면 1차의 Breusch-Pagan 결과(이분산)를 이것으로 설명할 수 있다
- [ ] M2·M3에서 기상 계수의 부호·크기가 M0와 어떻게 달라졌는지 메모한다
- [ ] 각 모형의 AIC, 주요 계수를 `reg_ladder.csv`로 저장한다

## 1B-3. 노출 변수 선택과 비례성 검정 (반나절) `[결정]`

offset은 "노출이 2배면 고장도 2배"라는 가정이다. 이것을 검정한다. 계절 효과를 먼저 넣은 상태에서 봐야 한다. 그렇지 않으면 여름에 대여도 많고 고장률도 높은 계절성이 log(노출) 계수에 섞인다.

```python
f_ctrl = ("tavg + np.log1p(rain_mm) + snow_any + humidity + solar + C(dow) + is_holiday"
          " + fs1 + fc1 + fs2 + fc2 + covid + C(year)")

rows = []
for e in ["rentals", "dist_km", "use_hours"]:
    nb = smf.negativebinomial(f"total_faults ~ np.log({e}) + {f_ctrl}", data=d.dropna(subset=[e])).fit(disp=0, maxiter=500)
    lo, hi = nb.conf_int().loc[f"np.log({e})"]
    rows.append({"exposure": e, "coef": nb.params[f"np.log({e})"], "lo": lo, "hi": hi, "AIC": nb.aic})
pd.DataFrame(rows)
```

판정
- [ ] **AIC가 가장 낮은 노출**을 고른다. 차이가 10 미만이면 해석이 쉬운 것(대여 건수 또는 이동거리)
- [ ] log(노출) 계수의 95% 구간이 1을 포함 → offset 사용
- [ ] 1보다 뚜렷이 작다(예: 0.8) → 그 자체가 발견이다(노출이 늘수록 대당 고장이 덜 늘어난다). 이때는 offset 대신 `np.log(노출)`을 설명변수로 두고, 결정 로그와 보고서에 기록한다
- [ ] 선택 결과를 `d["expo"]`에 반영한다

## 1B-6. 핵심 산출물 — 1차 OLS vs 새 NB 비교표 (반나절)

결과 자체보다 이 대비표가 재수행의 기여를 가장 잘 보여준다.

`output/tables/reg_ols_vs_nb.csv` 형식:

| 변수 | 1차 OLS 계수(유의성) | 새 NB IRR(HAC 95% CI) | 무엇이 바뀌었나 | 이유 |
|---|---|---|---|---|
| 대여량 | 0.0044 (t 125) | offset(계수 1 고정, 비례성 검정 결과) | 설명변수 → 노출 | 노출은 원인이 아니라 기회의 양 |
| 강수 | 5.20 (OLS 유의, HAC 비유의) | 당일 IRR, 전날 IRR | 당일 음(−), 전날 양(+)으로 분리되는지 | 두 효과가 상쇄돼 1차 계수가 작고 불안정했을 가능성 |
| 기온 | 선형(대체로 비유의) | U자 곡선 | 선형 → 비선형 | 혹한·혹서 모두 상승 |
| 요일 | 없음 | 월~일 IRR | 새로 추가 | 주말이 낮고 월요일이 높다(신고 지연) |
| … | | | | |

그리고 **1차 결론 vs 새 결론** 표를 만든다.

| 1차 결론 | 새 결과 | 판정 |

## 흔한 함정

- **식에 쓰는 열에 결측이 있다** → 행이 빠지면서 offset 길이가 어긋나 오류. 적합 전에 결측을 확인한다
- **`get_prediction()`에 offset을 빼먹는다** → 노출 1만 단위 기준 값이 아니라 노출 1 기준 값이 나온다
- **GLM 음이항에 alpha를 주지 않는다** → 기본값 1로 고정돼 결과가 틀린다. `fit_nb()`처럼 먼저 추정한다
- **스플라인 기저 계수를 IRR 표에 넣는다** → 해석 불가. 곡선 그림으로 보여준다
- **대여량을 offset과 설명변수에 동시에 넣는다** → 비례성 검정(1B-3) 때만 그렇게 한다
- **p값을 일반 표준오차로 읽는다** → 일별 시계열은 자기상관이 있다. HAC 기준으로 읽는다
- **테스트 구간(2025~)을 여기서 쓴다** → 쓰지 않는다
