# 추가 설명변수·파생변수 검토 — 실증 결과 포함

작성: 2026-09-13 / 데이터: dareungi_master.csv, 2021~2024 구간 기준

## 실증으로 확인한 누락 신호 4가지

### 1. 요일 (모형에 아예 없음, 효과 큼)
만 건당 고장률 (노출 통제): 월 44.3 / 화 42.5 / 수 42.6 / 목 41.6 / 금 40.1 / **토 34.5 / 일 35.3**
→ 주중이 주말보다 20~28% 높음

부품별 주말 하락폭: **안장 -19%, 페달 -16%**, 체인 -11%, 타이어 -9%
→ **"여가가 더 영향"이라는 가설과 반대 방향의 예비 증거.** 그리고 부품별 격차가 다름 = "목적별로 마모 부품이 다르다" 가설이 이미 보임

월요일 초과분은 전 부품 고르게 (금요일 대비 안장 +9.5%, 체인 +10.6%, 타이어 +13.5%, 페달 +12.6%)
→ 특정 부품 문제 아님 = **주말 발생 고장의 월요일 신고 지연** 증거

### 2. 노출 통제 시 계절성 부활 — 부품별로 완전히 다름
월별 만건당 고장률 지수 (각 부품 평균=100):
| 부품 | 2월 | 8월 | 진폭 |
|---|---|---|---|
| **타이어** | 56 | **164** | **108** (거의 3배) |
| 페달 | 61 | 135 | 74 |
| 체인 | 68 | 105 | 50 |
| 안장 | 83 | 99 | **28** (거의 평평) |

→ 수준 기준으로는 대여량 계절성에 묻혀 안 보이던 것. 보고서의 "타이어가 기상에 가장 민감"을 정량적으로 강하게 뒷받침
→ 안장의 낮은 진폭 = 안장은 기상이 아니라 **사용 또는 시간**의 함수 → 정적 노출 가설로 연결

### 3. 당일 비보다 '어제 비'가 중요
당일 무강수인 날만: 전날 무강수 40.5 / 약한비 42.1 / **보통비 46.9 (+16%)** / 강한비 41.7
반면 **당일** 강한 비(rain=3)는 34.4 (-14%)
→ 비 오는 날엔 안 탐(노출↓), 비 온 **다음날** 젖은 노면·오염·부식이 고장 유발
→ **rain 계수가 왜 작고 불안정했는지 설명됨** (두 효과 상쇄). `rain.shift(1)` 한 줄로 해결

### 4. 기온 U자형
혹한(≤0℃) 46.9 (+17%) / 혹서(≥28℃) 43.1 (+8%) / 전체 40.1
→ 선형 계수로는 못 잡음. temp가 비유의했던 이유. 스플라인/구간 더미 필요

## A. 일별 총량 분석 추가 변수

### A-1. 가장 중요한 결측: 운영 대수 · 차령
`고장 = 운영 대수 × 대당 고장률`인데 모형에 분모가 없음. rentals에는 **대수와 이용강도가 섞여 있음**.
반기별 확인: 누적 대여량이 쌓일수록 고장률은 **하락** (2021H2 52.2 → 2024H1 35.7) → 노후화가 아니라 신규 도입/정비 개선 작동 중. 대수 데이터 없이는 더 진행 불가.
출처: 서울시설공단 연보, 대여소 마스터 정보(OA-21235) 거치대수, 서울시 보도자료

### A-2. ASOS 확장 (같은 지점 108에서 무료)
일 최고/최저기온 → **일교차** (타이어 공기압·재료 팽창), 평균·최대 풍속, 일조시간, **지면온도**(여름 노면), 최소 상대습도, 안개·시정
외부: **미세먼지 PM10/PM2.5 (에어코리아)** — 이용량 영향 + 체인 오염 마모, 황사일

### A-3. 달력·정책·외생
공휴일/전후일/연휴길이, 학기·방학, **코로나 거리두기 단계(2020~2022, 2020년 이상치의 유력 원인)**, 요금제 변경, 신규 대여소 개소 수, 단말기 교체 **진행률**(더미 아닌 연속값), 공유 킥보드·전기자전거 등록 대수(대체 효과)

### A-4. 노출 재정의
대여 건수 → **총 이동거리 또는 총 이용시간**. `이용정보(일별)`에 운동량·이용건수 존재

## B. 개체 단위 추가 변수

**B-1 주행 노출**: 누적 주행거리/횟수/시간, **통행당 평균 거리**(같은 총거리라도 정지-출발 횟수가 다름), **정지-출발 추정 횟수 = 누적 통행 횟수**, 평균 속도, **속도 분산**, 이상 통행 비율(극단 저속 = 끌고 감/고장 상태 주행)

**B-2 지형**: **누적 상승고도와 하강고도 분리**(등판=체인·페달 고토크 / 내리막=브레이크·타이어 제동발열 — 합치면 정보 소멸), 구간 최대 경사, 우회율, **대여소 자체 고도**(고지대 배치 = 상시 등판), 왕복 비율

**B-3 정적 노출 (놓치기 쉬운 축)**: 자전거는 시간 대부분을 세워져 있고 열화는 주차 중에도 진행
- 누적 옥외 노출 일수(= 투입 후 경과일, 주행과 무관한 축), 그중 누적 강수 노출일·일사량·혹한일
- **동결-융해 사이클 횟수** (재료 열화 표준 지표, 0℃ 교차 횟수)
- 가설: **안장·그립·타이어 고무 = 옥외 노출 시간에 비례 / 체인·브레이크 = 주행거리에 비례**
- 안장 계절진폭 28(최저)이 이 가설과 일관 → **"주행 마모형 vs 시간 열화형" 부품 분류** 결과 도출 가능 → 정비 전략이 달라짐(주행거리 기준 교체 vs 경과일 기준 교체)

**B-4 재배치 (독창성 높음)**: 직전 반납 대여소 ≠ 다음 대여 대여소 → 트럭 이동. **대여이력만으로 추정 가능**
- 누적 재배치 횟수, 재배치 이동거리
- 가설: 적재·하역 충격 → 안장·핸들·페달·휠 손상
- 서울시 연 수십만 건 재배치 → 유의하면 재배치 방식 개선이라는 실무 제언. 바르셀로나 논문에도 없음

**B-5 이용자 구성 프록시**: `이용정보(일별)` OA-15246 (2017~2026, 반기)에 **대여소별 정기권유무·성별·연령대·운동량·이용건수**. 자전거번호는 없지만 **대여소×일자로 조인 가능**
- 정기권 비율 → 통근 vs 관광, 연령대 구성, **운동량**(거리·속도·경사 기반 공식 지표)
- 주의: 대여소 평균이므로 **생태학적 오류** 유의. "탄 사람"이 아니라 "놓인 환경"으로 해석

**B-6 자전거 이력**: 투입 후 경과일, 직전 고장 후 경과 거리·일수, 과거 고장 횟수(부품별/전체), **타 부품 고장 이력**(바르셀로나가 사용), **신고 후 운행 지속 여부**(수리 안 된 채 주행 → 2차 고장 촉진, 쟁점 1의 gap 변수와 동일 재료), 신고 간격의 추세

**B-7 공간 고정효과**: 주 활동 자치구, 한강 인접 대여소 이용 비율, 대여소 거치대수

## 우선순위
**즉시 (추가 수집 불필요)**: ① 요일·공휴일 더미 ② 전날 강수·강수 후 경과일 ③ 기온 U자형(스플라인/구간) ④ 부품별 월 계절지수 또는 Fourier ⑤ 노출을 이동거리로 교체
**수집 필요·가치 큼**: ⑥ **운영 대수·평균 차령** ⑦ ASOS 확장 ⑧ 미세먼지 ⑨ 공휴일·거리두기 달력
**개체 단위 전용**: ⑩ 정적 노출(옥외 노출일·동결융해) ⑪ 재배치 횟수 ⑫ 통행당 평균거리·정지출발 횟수 ⑬ 누적 상승/하강고도 분리

## 판단 기준
변수 추가로 R²는 오름(0.797→0.915). 그러나 1차 분석의 교훈은 **설명력이 아니라 노출 통제**.
새 변수마다 물을 것: **"이건 노출의 또 다른 얼굴인가, 노출 통제 후에도 남는 위험 요인인가?"**
- 전자(넣어도 문제 그대로): 누적 대여량, 이동평균 대여량 — rentals의 변형일 뿐
- 후자(진짜 답): 요일, 전날 강수, 기온 U자형, 옥외 노출, 재배치
