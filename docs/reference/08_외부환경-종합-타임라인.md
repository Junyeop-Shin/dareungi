# 따릉이 외부 환경 종합 — 정책·앱·운영·교통·사회 요인 (2015~2026)

> 조사일 2026-10-05. 서울시·서울시설공단 보도자료, 내 손안에 서울, 시의회 인용 기사, 언론, 앱스토어 기록을 웹에서 찾았다.
> **확인** = 원문을 열어 본 것(요약 도구를 거쳤으므로 보고서에 인용할 숫자는 링크를 직접 다시 열어 본다) / **2차** = 다른 기사·시의원 자료 인용 / **추정** = 해석.
> 신고율 변화 원인(2021-04, 2025-03, QR 전환)은 `07_신고율-변화-원인-조사.md`에 따로 정리했다. 이 문서는 그 밖의 환경 전체를 다룬다.
> 날짜·출처는 `data/raw/external/events.csv`(56행)에 행 단위로 정리했다. `event` 이름 앞부분이 종류: `service_*` 전체 중단, `station_closed_*` 대여소 중지, `covid_*`, `pass_*`·`*_fare_up` 요금, `app_*`·`callcenter_*` 신고 경로.
