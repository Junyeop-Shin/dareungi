결정 주제: $ARGUMENTS

1. 런북에서 해당 체크포인트(또는 결정 주제)의 판단 기준을 찾는다.
2. 판단에 필요한 수치를 이미 저장된 결과(`output/tables/`, 노트북 출력, 결정 로그)에서 모은다. 없으면 무엇을 계산해야 하는지 말하고 계산 여부를 묻는다.
3. `docs/WORKFLOW_사람-AI_역할분담.md`의 "결정 요청 형식"으로 제시한다: 배경 수치 → 선택지 2~3개 → 장단점 → AI 추천과 이유 → 결정하면 바뀌는 것.
4. **사람이 고를 때까지 다음 작업을 진행하지 않는다.** 결정 로그도 아직 쓰지 않는다.
